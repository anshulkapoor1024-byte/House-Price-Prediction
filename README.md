# House Price Prediction using Multiple Linear Regression 

This is one of my beginner Machine Learning projects where I used **Multiple Linear Regression** to predict house prices.

The main idea of this project is simple: instead of using just one factor to predict the price of a house, we use multiple factors together.

# What I Used

For predicting the house price, I used:

* Area of the house
* Number of bedrooms
* Age of the house
* Distance from the city

The model learns from these factors and then predicts the expected price of a house.

# Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

# What I Did in This Project

In this notebook, I:

1. Loaded the dataset.
2. Checked and explored the data.
3. Selected the required features.
4. Split the data into training and testing sets.
5. Built a Multiple Linear Regression model.
6. Trained the model using the training data.
7. Made predictions using the test data.
8. Checked the performance of the model using MSE, RMSE and R² score.

# Result

The model achieved an **R² score of around 97.42%** on the test data.

This was a great project for me to understand how **Multiple Linear Regression works in a real dataset** and how different features can affect the final prediction.
